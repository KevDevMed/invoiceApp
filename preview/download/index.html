InvoiceApp for macOS

An offline-first invoicing app: clients, invoices, PDF export and reports, stored in a single SQLite file on your own Mac. It also runs a local AI assistant on your machine, with no account and no server.

If macOS says the app is damaged or from an unidentified developer

The app is fine. This dialog appears when the build you downloaded is not signed with an Apple Developer certificate, so Gatekeeper quarantines it. If it appears, let the app through once — after that it opens normally. If the app opens without any warning, you have a signed build and can skip this section.

  1. Drag InvoiceApp into your Applications folder.
  2. Right-click (or Control-click) the app icon and choose Open. Do not double-click it — double-clicking gives you the dialog with no way through.
  3. Click Open again in the dialog that appears.

If macOS still refuses, clear the quarantine flag from Terminal and open the app again: 

xattr -dr com.apple.quarantine /Applications/InvoiceApp.app

System requirements

Operating system
macOS 12 Monterey or later
Processor
Apple Silicon (M1 or newer) — use the arm64 download above; Intel — use the x64 download
Disk space
About 8 GB free if you want to use the assistant — that is the model weights. The app itself and your invoice database are a few hundred megabytes at most.

What runs where

  • Your data never leaves the machine. Clients, invoices and settings live in one SQLite file in your user data folder. There is no account, no sync and no telemetry.
  • The assistant runs on-device. Model weights are downloaded once from Hugging Face, then every prompt and reply is processed locally by the app's bundled llama.cpp runtime. Nothing you type is sent anywhere.
  • The browser preview is a different thing. It is there so you can look at the interface without installing anything. It uses throwaway demo data on the preview server, and it cannot export PDFs or run a model — both need the desktop app.
